# Zigbee2MQTT

Two containers behind the `zigbee2mqtt` compose profile:

- **mosquitto** — MQTT broker, bound to `127.0.0.1:1883` on the host so
  Home Assistant (running with `network_mode: host`) can reach it via
  loopback, and to the `frontend` docker network so Z2M reaches it via
  docker DNS as `mosquitto:1883`.
- **zigbee2mqtt** — talks to the Sonoff Dongle Max over the LAN at
  `tcp://192.168.22.199:6638`, publishes device state to MQTT, exposes
  its web UI on port 8080.

Caddy reverse-proxies `https://zigbee.roxell.se` to `zigbee2mqtt:8080`,
gated to the mgmt subnet. The dongle is a network appliance, not a USB
device — no host passthrough.

## First-time setup in Home Assistant

After `./setup.sh` has run and both containers are healthy, connect HA to
the broker.

### 1. Get the HA MQTT password

```sh
ssh skarpnacksalle 'grep ^MQTT_HA_PASSWORD ~/src/homelab/zigbee2mqtt/.env.secrets | cut -d= -f2'
```

Setup.sh generated this on first run and stored it in
`zigbee2mqtt/.env.secrets`. Same file holds the Z2M user password, which
Z2M reads via env_file.

### 2. Add the MQTT integration

In Home Assistant: **Settings → Devices & services → Add integration →
MQTT → Manually enter MQTT broker information**.

| Field    | Value             |
| -------- | ----------------- |
| Broker   | `127.0.0.1`       |
| Port     | `1883`            |
| Username | `homeassistant`   |
| Password | from step 1       |

Submit. HA connects to mosquitto. Because Z2M publishes with
`homeassistant: true`, any Zigbee device paired through Z2M afterwards
auto-appears in HA without per-device config.

### 3. Verify the bridge

In Z2M (`https://zigbee.roxell.se`) the coordinator at the top should
show as connected.

In HA, the MQTT integration card lists a **Zigbee2MQTT Bridge** device
with version, network channel, etc.

If the bridge is missing from HA, refresh the page. If still missing,
check `docker compose logs --tail 50 zigbee2mqtt` for the
`Connected to MQTT server` line.

## Pairing a Zigbee device

In Z2M's web UI:

1. Top right → **Permit join (all)** → 5 minutes.
2. Put the device in pairing mode:
   - **IKEA TRÅDFRI bulb**: power-cycle 6 times.
   - **IKEA Vindstyrka air sensor**: press the small button for 5
     seconds until the LED blinks.
   - **Sonoff Zigbee sensor**: hold the side button for 5 seconds.
3. Device appears in Z2M's **Devices** tab within 10–30 seconds.
4. Device appears in HA under **Settings → Devices & services → MQTT →
   Devices** another 10 seconds later.
5. Turn **Permit join** back off.

Pair mains-powered devices (bulbs) first. They become Zigbee routers and
extend the mesh for battery-powered sensors.

## Troubleshooting

| Symptom                              | First place to look                       |
| ------------------------------------ | ----------------------------------------- |
| `https://zigbee.roxell.se` returns 502 | `docker compose logs --tail 20 caddy zigbee2mqtt` |
| Device does not pair                 | `docker compose logs --tail 50 zigbee2mqtt` during pair |
| MQTT integration shows nothing       | `docker compose logs --tail 20 mosquitto` for HA connect |
| Z2M shows "coordinator disconnected" | `nc -zv 192.168.22.199 6638` from the server |
| HA says "Invalid IP in X-Forwarded-For" | proxy_headers snippet wrong, see `caddy/Caddyfile` |

## Files

- `compose.yml` — mosquitto and zigbee2mqtt service definitions
- `.env.secrets` — MQTT users + passwords (generated by setup.sh, not in git)
- `/opt/stack/mosquitto/config/mosquitto.conf` — broker config
- `/opt/stack/mosquitto/config/passwd` — hashed user passwords
- `/opt/stack/mosquitto/data/` — retained messages, persistent state
- `/opt/stack/zigbee2mqtt/data/configuration.yaml` — Z2M config
- `/opt/stack/zigbee2mqtt/data/coordinator_backup.json` — coordinator
  state, restore with `docker compose restart zigbee2mqtt`
- `/opt/stack/zigbee2mqtt/data/database.db` — paired-device database

## Resetting from scratch

If you ever need to wipe the Zigbee network and start over:

```sh
cd ~/src/homelab
docker compose stop zigbee2mqtt
sudo rm -rf /opt/stack/zigbee2mqtt/data/coordinator_backup.json
sudo rm -rf /opt/stack/zigbee2mqtt/data/database.db
docker compose start zigbee2mqtt
```

Z2M forms a fresh Zigbee network on next start. All paired devices have
to be re-paired.

To rotate the MQTT passwords:

```sh
rm ~/src/homelab/zigbee2mqtt/.env.secrets
sudo rm /opt/stack/mosquitto/config/passwd
./setup.sh
docker compose restart mosquitto zigbee2mqtt
```

Then re-enter the new HA password in **HA → Settings → Devices &
services → MQTT → Configure**.
